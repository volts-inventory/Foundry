        ③ How it runs

        The stack pins the verification gates (build/test/smoke commands). Non-Python stacks need their toolchain installed on the server — a missing toolchain fails the gate loudly, it never fakes a pass.

        ④ Scale & limits

        Tickets run in dependency order; each specialty works at most this many at once, the rest queue.

        A multi-service request (e.g. a site with users + posts) is auto-built as a PLATFORM — split into web / backend / data services (the backend owns the REST API, auth & domain logic), each auto-deepened, then stitched into one monorepo. A single thing builds as one service.
